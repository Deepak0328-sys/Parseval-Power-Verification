# Parseval Power Verification Using MATLAB

A MATLAB-based Digital Signal Processing (DSP) project that verifies Parseval's theorem by comparing the average mean-square power of a signal in the time domain and frequency domain using Fast Fourier Transform (FFT) analysis.

## Features

* Generate sine, cosine ,square wave signals along with random signals.
* Generate noisy signals using a selectable base waveform.
* Configure sampling frequency, number of samples, amplitude, and signal frequency.
* Calculate average mean-square power in the time domain.
* Calculate average mean-square power in the frequency domain using FFT.
* Compute the absolute verification error.
* Visualize the signal waveform, frequency spectrum, and power comparison.

## Technologies Used

* MATLAB
* Digital Signal Processing (DSP)
* Fast Fourier Transform (FFT)

## Objective

To demonstrate the practical verification of Parseval's theorem by confirming that the average mean-square power calculated in the time domain matches the corresponding value calculated in the frequency domain.

## How to Run

1. Download or clone this repository.
2. Open MATLAB.
3. Open the main MATLAB script.
4. Run the program.
5. Enter the requested signal parameters.
6. Select the desired signal type.
7. Observe the calculated power values, verification error, and plots.

## Applications

* Digital signal processing education.
* Time-domain and frequency-domain signal analysis.
* Numerical verification of signal properties.
* MATLAB-based engineering experiments.
